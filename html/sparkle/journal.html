Tools for those in controls,
built for the field.

A reference site for building-controls people. Open calculators and lookups for the math you don't want to redo at the panel — BACnet/IP, Modbus registers, signal scaling, psychrometrics, thermistors. Alongside, a growing set of explainers that walk through hydronic loops, load piping, VFDs, and pump control end-to-end.

IStart Here

Tools
Calculators & lookups →
Calculators and lookups for the parts of the job that come up over and over — psychrometric staging, signal scaling, register and address conversions, thermistor curves, a practice VFD keypad. Open one, get an answer, get back to work.
 Education
Learn the fundamentals →
A connected set of explainers, not a glossary. The current arc: PID control → hydronic loops → load piping → VFDs → pump control, each page asking one question and answering it with diagrams, worked examples, and the occasional interactive widget.

IIAbout

Controls Programmer · Northeast U.S. · Est. 2026

Hi, I'm a controls programmer based in the Northeast U.S. This is a side project I'm working on while exploring vibe coding. There's a genuine gap in easy reference websites and educational resources for this trade. This site started as just a way to have some easy reference tools in one place, but has expanded to include much more.

All anecdotes on this site are real things I've encountered, not AI generated. Although it may refine my writing for some of them.

Bug reports, tool requests, or feedback — get in touch.

IIIEducation Sample

PID is three knobs that, together, push a process variable (PV — the thing you're measuring) toward a setpoint (SP — the value you want it to hold). This is a common sense walk through what each one does on a typical HVAC loop, plus three small sims you can play with one knob at a time.
