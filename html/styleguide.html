Design system

The living reference for the controlsfreak.dev visual language. The site speaks in two registers: a default software register (cool slate, AX-sharp, square corners) for all the chrome, tools, lessons, and drills; and an equipment register (warm device face, lit dot-matrix LCD) used only where a page depicts real hardware. Both render in a dark default theme and a light theme — flip Theme in the nav to compare. Every colour below is a CSS custom property, so the palette swaps wholesale per theme.

Equipment register

device sims · VFD/DMM · hardware widgets
