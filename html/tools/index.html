Tools

Calculators, converters, and viewers for the day-to-day. Pick one — no login, nothing to install, nothing tracked.

Analog I/O
Signal Scaling Calculator
mA / V signal ↔ engineering units, with % of span and a 2-point → slope/offset tab ready to paste into Niagara's ProxyExt.
 Modbus
Modbus Register Viewer
A 16-bit register laid out as a clickable bit grid, two-way bound to decimal / hex, with dec / hex / binary readouts.
 Loops
PID Tuning Helper
A step-response simulator — gain · reset · rate (or Ti·Td / proportional band), preset tunings, a PV-vs-setpoint plot, and a symptom → tuning-move cheat sheet.
 BACnet
BACnet/IP Hex Converter
The hex address strings EBO shows for BACnet/IP devices ↔ dotted-decimal IP and UDP port, both directions.
 HVAC
Psychrometric Chart
Walk an AHU through its processes — mix outdoor + return air, then cool, heat, and humidify — on an interactive ASHRAE psychrometric chart that follows the header's US / Metric toggle. Drag OA and RA, or type leaving conditions; coil capacities appear when you set the airflow.
 HVAC
Economizer Ratio Helper
Required %OA to mix outdoor and return air down to a mixed-air dry-bulb setpoint, with a feasibility verdict and an OA-vs-RA enthalpy-changeover sanity check for high-end economizer logic.
 HVAC
Air-Mixing Calculator
Blend three air streams by mass flow (CFMs at the panel) or mass fraction (percentages off a schematic) and read out the full mixed-air state — dry-bulb, humidity, enthalpy, dew point.
 HVAC
Coil-Sizing Calculator
Total, sensible, and latent capacity for a cooling or heating coil from its entering and leaving air — or run it backwards to solve the leaving-air state from a known load.
 HVAC
Refrigerant P-T & Superheat Calculator
Saturation pressure ↔ temperature for R-410A, R-22, R-134a, R-407C, R-404A and R-454B — bubble and dew both, so blend glide is in plain sight — plus a superheat / subcooling check off a measured line temperature.
 Sensors
Thermistor / RTD Calculator
Temperature ↔ resistance for the common HVAC sensors — 10K Type II / III, Johnson 8.7K, Schneider Type 5, 20K, 3K, 1K Balco, Pt100, Pt1000 — looked up both ways, or identify an unknown sensor from measured readings.
 Drives
Mock VFD Interface
Practice navigating a generic drive's parameter tree on a clickable keypad — feel the run-source / speed-source gating before you're at a real drive. Paired with the VFD Basics explainer.
 Logic
Function-Block Editor
A graphical wiresheet sandbox — drop logic, math, timer, and PID blocks, wire them up, and watch a control sequence run live. Five worked examples built in. Paired with the Function-Block Basics explainer.
