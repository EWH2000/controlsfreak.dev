Tools

Calculators, converters, and viewers for the day-to-day. Pick one — no login, nothing to install, nothing tracked.

Analog I/O
Signal Scaling Calculator
mA / V signal ↔ engineering units, with % of span and a 2-point → slope/offset tab ready to paste into Niagara's ProxyExt.
 Modbus
Modbus Register Viewer
A 16-bit register laid out as a clickable bit grid, two-way bound to decimal / hex, with dec / hex / binary readouts.
 Loops
PID Tuning Helper
A step-response simulator — gain · reset · rate (or Ti·Td / proportional band), preset tunings, a PV-vs-setpoint plot, and a symptom → tuning-move cheat sheet.
 BACnet
BACnet/IP Hex Converter
The hex address strings EBO shows for BACnet/IP devices ↔ dotted-decimal IP and UDP port, both directions.
 HVAC
Psychrometric Chart
Walk an AHU through its processes — mix outdoor + return air, then cool, heat, and humidify — on an interactive ASHRAE psychrometric chart that follows the header's US / Metric toggle. Drag OA and RA, or type leaving conditions; coil capacities appear when you set the airflow.
 Sensors
Thermistor / RTD Lookup
Temperature ↔ resistance for the common HVAC sensors — 10K Type II / III, Johnson 8.7K, Schneider Type 5, 20K, 3K, 1K Balco, Pt100, Pt1000 — with the full R/T table for the selected type.
 Drives
Mock VFD Interface
Practice navigating a generic drive's parameter tree on a clickable keypad — feel the run-source / speed-source gating before you're at a real drive. Paired with the VFD Basics explainer.
