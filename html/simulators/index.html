Simulators

Interactive models you can poke at, right in the browser. Practice on the controls before you're standing in front of the real thing — no login, nothing to install, nothing tracked.

Loops
PID Tuning Helper
A step-response simulator — gain · reset · rate (or Ti·Td / proportional band), preset tunings, a PV-vs-setpoint plot, and a symptom → tuning-move cheat sheet.
 Drives
Mock VFD Interface
Practice navigating a generic drive's parameter tree on a clickable keypad — feel the run-source / speed-source gating before you're at a real drive. Paired with the VFD Basics explainer.
 Logic
Function-Block Editor
A graphical wiresheet sandbox — drop logic, math, timer, and PID blocks, wire them up, and watch a control sequence run live. Five worked examples built in. Paired with the Function-Block Basics explainer.
