기능 블록 편집기 논리

Niagara, EBO, Distech에서 사용하는 것과 같은 그래픽 와이어시트 실습 환경입니다. 블록을 추가하고 출력 핀과 입력 핀을 연결하면 실시간 스캔 루프가 시트 전체로 값을 전달합니다. 특정 제품 하나를 모사하기보다 제어 시퀀스를 구성하는 감각을 익히는 데 목적이 있습니다. 처음이신가요? 기능 블록 기초부터 시작하기 →

데스크톱 도구

와이어시트의 블록 연결은 포인터와 넓은 화면이 필요한 드래그 작업입니다. 노트북이나 데스크톱에서 이 페이지를 열어 시퀀스를 구성하고 실행하세요. 손가락 하나로 블록을 끌면서 시트를 동시에 이동할 수 없으므로 의도적으로 포인터 전용으로 설계했습니다. 다음 개념을 익힐 수 있습니다.

  • 시트는 왼쪽에서 오른쪽으로 흐릅니다. 센서와 상수 같은 소스는 왼쪽, 논리와 연산은 가운데, 출력은 오른쪽에 둡니다. 와이어시트를 신호가 이동하는 경로로 읽으세요.
  • 출력에서 입력으로, 같은 형식끼리 연결합니다. 블록 오른쪽의 출력 핀을 다른 블록 왼쪽의 입력 핀에 연결합니다. 아날로그는 아날로그에, 디지털은 디지털에만 연결할 수 있습니다.
  • 비교 블록은 아날로그를 디지털로 바꿉니다. 초과 또는 미만 블록이 두 숫자를 비교해 TRUE 또는 FALSE를 출력합니다. 측정값을 켜짐·꺼짐 판단으로 바꾸는 다리입니다.
  • 래치는 상태를 유지하고, 루프는 안정됩니다. SR 래치는 마지막 설정 또는 복귀 상태를 기억합니다. 피드백 와이어는 이전 스캔의 값을 전달하므로 루프가 멈추지 않고 매 틱마다 안정됩니다.
  • 약 초당 10회 스캔으로 실행됩니다. 소스를 바꾸면 실제 제어기가 프로그램을 반복 실행하듯 시트 전체를 다시 계산합니다.
  • 블록의 단위는 실제 단위입니다. PID 블록의 Ti와 Td는 초 단위입니다. 따라서 PID 튜닝 도우미의 기본 리셋 단위(repeats/min)로 조정했다면 값을 옮기기 전에 Ti (s) = 60 ÷ reset으로 변환하세요.

와이어시트가 처음이신가요? 기능 블록 기초에서 같은 개념을 설명하며 휴대전화에서도 편하게 읽을 수 있습니다.

실행 중
아날로그(숫자) 디지털 TRUE 디지털 FALSE

사용 방법

팔레트의 블록을 클릭해 시트에 놓고 제목 표시줄을 끌어 위치를 옮깁니다. 와이어를 연결하려면 출력 핀(오른쪽 가장자리)을 클릭한 다음 호환되는 입력 핀(왼쪽 가장자리)을 클릭하세요. 아날로그끼리, 디지털끼리 같은 형식만 연결됩니다. 블록이나 와이어를 클릭해 선택하고 Delete 키로 삭제하거나 Escape 키로 진행 중인 와이어 연결을 취소할 수 있습니다. 캔버스 아래의 속성 편집기에서는 선택한 블록의 매개변수를 즉시 변경합니다. 블록 배치와 연결에는 마우스 또는 트랙패드가 필요하지만, 예제 버튼과 속성 편집기, 시뮬레이션 버튼은 키보드로도 조작할 수 있습니다.

시퀀스는 초당 10회 계산됩니다. 순수 논리는 한 번의 패스에서 안정되며, 출력이 자체 연산 체인으로 되돌아가는 피드백 루프는 이전 틱의 값을 전달하므로 래치가 상태를 유지하고 루프가 멈추지 않습니다. 소스와 출력 블록에는 현재 값이 표시되고, TRUE를 전달하는 디지털 와이어는 녹색으로 바뀝니다. 작업 내용은 저장되지 않습니다. 새로 시작하려면 페이지를 다시 불러오거나 예제를 선택하세요.

DIVIDE 블록은 제수가 0이면 0을 출력합니다. 이는 하위 비교 블록이 Infinity 또는 NaN을 읽지 않도록 하는 보호 기능입니다.
