도구 · 습공기선도

습공기선도 HVAC

공기조화기의 습공기 공정을 단계별로 해석합니다.
외기(OA)와 회기(RA)를 혼합한 다음 냉각, 가열, 가습합니다. 단계 버튼으로 공정을 선택해 패널에서 매개변수를 수정하거나 선도에서 OA와 RA 상태점을 끌어 옮기세요. 급기(SA) 상태와 모든 중간 상태점이 함께 갱신됩니다. 습공기선도가 처음인가요? 습공기선도 기초 레슨에서 선도의 일곱 가지 물성과 특히 주의할 을 먼저 설명합니다.

입력란에는 예제가 미리 채워져 있습니다. 확인하려는 값으로 수정하세요.

이 선도는 넓은 화면에 맞춰져 있습니다. 휴대전화에서는 3열 작업 공간이 한 열로 바뀌고 캔버스가 압축됩니다. 휴대전화에서는 위 입력 열에 각 상태를 직접 입력하는 것이 가장 빠릅니다. 선도에서 OA / RA를 끌어 옮길 수도 있지만, 노트북이나 태블릿을 사용하면 더 편하게 읽을 수 있습니다.

공기조화기

선도 범위

공기조화기로 유입되는 외기입니다. 선도에서 이 점을 끌어 옮기거나 여기서 값을 수정하세요.

공조 공간에서 돌아오는 회기(RA)입니다. 선도에서 이 점을 끌어 옮기거나 여기서 값을 수정하세요.

OA와 RA를 질량 가중 혼합합니다. 혼합 상태점은 선도의 OA–RA 직선 위에서 RA로부터 OA 방향으로 외기 비율(OA%)만큼 이동한 위치에 놓입니다.

냉각 코일

코일 출구 상태입니다. 출구 건구온도는 입구 값 이하여야 하며, 냉각 코일을 통과하면서 절대습도(함습비, W)가 증가할 수는 없습니다.

가열 코일

만 가열하며, 코일 전·후의 절대습도(함습비, W)는 변하지 않습니다. 출구 건구온도는 입구 값 이상이어야 합니다.

가습기

증발식 패드나 습윤 메디어를 사용한 단열(일정한 ) 가습입니다. 수분을 더하면 가 약간 내려갑니다. 출구 상대습도는 입구 값 이상이어야 합니다.

급기(SA)는 공정 연속선에서 활성화된 마지막 단계의 출구 상태입니다. 전체 물성표는 오른쪽에 있습니다.

습공기선도

굵은 녹색 = 포화곡선, 오른쪽으로 상승하는 가는 곡선 = 일정 상대습도, 가는 점선 = 일정 입니다. 공정 구간은 색상으로 구분합니다. 회색 = 혼합, 파란색 = 냉각 / 제습, 주황색 = 가열, 녹색 점선 = 단열 가습입니다.
