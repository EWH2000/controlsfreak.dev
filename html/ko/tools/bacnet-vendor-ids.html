BACnet 벤더 ID 조회 BACnet

ASHRAE가 할당한 모든 벤더 ID를 하나의 필터 가능한 표로 제공합니다. 장치가 보고한 번호를 붙여 넣으면 제조사를 확인할 수 있습니다.
벤더 ID는 모든 BACnet 장치가 Device 객체에 보유하고 I-Am에서 알리는 Vendor_Identifier(속성 120)입니다. ASHRAE가 제조사마다 한 번 할당하고 영구히 유지하는 16비트 번호입니다. 디코더 입력란에 번호를 입력하거나 전체 등록부 표를 ID 또는 회사명으로 필터링하세요. 여기에는 ID와 조직명만 다시 게시하며, 표 아래에 데이터 스냅샷 날짜를 표시합니다.

입력란에는 예제가 미리 채워져 있습니다. 확인하려는 번호로 수정하세요.

입력

디스커버리 로그, 속성 시트 또는 Wireshark의 I-Am 디코드 결과에서 Vendor_Identifier로 표시되는 번호입니다.

출력

조직 —

ASHRAE 공식 등록부인 bacnet.org 할당 벤더 ID에서 가져왔습니다. 가져온 날짜 {{ bacnetVendorIds.retrieved }}, ID {{ bacnetVendorIds.maxId }}까지 {{ bacnetVendorIds.vendors | length }}건의 할당이 있습니다. ID는 한 번 할당하면 다시 배정하지 않으므로 번호는 항상 같은 등록자를 식별합니다. 다만 등록부가 회사명 변경과 인수에 맞춰 조직명을 수정하므로 현재 이름이 이 스냅샷보다 최신일 수 있습니다. 순서 중 비어 있는 번호는 철회되었거나 발급되지 않은 것이며, {{ bacnetVendorIds.maxId }}보다 큰 ID를 보고하는 장치는 이 스냅샷보다 최신일 수 있습니다. 여기에는 ID와 조직명만 다시 게시하고 등록부의 연락처 열은 의도적으로 제외했습니다.

BACnet 벤더 ID란

ASHRAE가 제조사에 한 번 할당한 뒤 절대 재할당하지 않는 16비트 번호이며, Device 객체의 Vendor_Identifier(속성 120)로 공개됩니다. 회사에서 출하한 모든 장치는 같은 번호를 보고합니다. 개별 장치가 아니라 제조사를 식별하는 값입니다. 등록이 무료이므로 목록이 길고 현장에서 거의 접하지 않는 회사명도 많이 포함되어 있습니다.

등록부의 첫 두 행에는 그 기원이 담겨 있습니다. ID 0은 ASHRAE 자체이고 ID 1은 초기 BACnet 상호운용성 시험을 조직하고 개최한 NIST입니다. 그 뒤의 항목은 업계가 BACnet을 채택한 대략적인 순서로 이어집니다.

현장에서 벤더 ID를 접하는 곳

보통 세 곳에서 접합니다. Who-Is 디스커버리 중 장치가 응답하는 I-Am, 즉 워크스테이션의 디스커버리 로그에서 장치 인스턴스 옆에 표시되는 값, Device 객체의 속성 시트에서 확인하는 속성 120, 그리고 Wireshark 캡처에서 디코딩한 I-Am 입니다. 세 경우 모두 가공되지 않은 같은 번호가 표시되며 바로 그럴 때 이 표가 필요합니다.

벤더 ID는 프로토콜의 전용 부분에 네임스페이스도 제공합니다. 객체 유형 128–1023과 번호가 높은 속성은 벤더별로 다릅니다. 범위는 BACnet 객체 참조에서 확인할 수 있습니다. 따라서 캡처에서 표준에 정의되지 않은 객체 유형을 발견하면 가장 먼저 "어느 벤더의 장치인가"를 확인해야 하며, 벤더 ID가 그 답을 줍니다.

예약되어 할당되지 않는 벤더 ID

555, 666, 777, 888, 911, 999, 1111의 일곱 번호는 ASHRAE가 보류하며 벤더에 할당하지 않습니다. 장치나 캡처에서 이 번호 중 하나가 보고되면 실제 제조사의 제품이 아니라 자리표시자, 시험용 스택 또는 잘못된 구성입니다.

그 밖에 순서에서 비어 있는 번호는 등록이 철회되었거나 발급되지 않은 번호입니다. ID는 재할당되지 않으므로 계속 비어 있습니다. 또한 ASHRAE는 새 ID를 계속 발급하므로 이 스냅샷의 상한보다 큰 번호는 대개 잘못된 값이 아니라 표보다 최신인 장치를 뜻합니다.
