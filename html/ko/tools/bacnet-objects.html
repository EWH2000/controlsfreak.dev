BACnet 객체 참조 BACnet

제어기, 패킷 캡처 도구 또는 워크스테이션이 이름 대신 보여 주는 숫자를 확인합니다.
객체 유형은 포인트의 종류를 나타내는 Object_Type 열거형입니다(유형 1 = Analog Output). 속성 ID는 객체에서 읽는 필드를 나타내는 Property_Identifier 열거형이며(속성 85 = Present_Value), 모든 객체 유형에서 같은 번호를 사용합니다. 공학 단위는 현장에서 자주 쓰는 Units 열거형을 분야별로 묶은 목록입니다. 이름, 번호 또는 기호를 입력하면 세 표를 모두 필터링합니다.

BACnet 객체 유형(Object_Type 열거형)

모든 객체 식별자에 포함되는 Object_Type 값입니다. AI/AO/AV와 BI/BO/BV는 장치에서 일상적으로 접하는 포인트의 약 5분의 4를 차지합니다.

이 필터와 일치하는 객체 유형이 없습니다.

ASHRAE 135-2020과 그 부록에 정의된 0–64 전체 범위입니다. 128 미만의 미할당 번호는 향후 표준판을 위해 ASHRAE가 예약했으며, 128–1023은 벤더 전용 범위입니다. 어떤 벤더의 확장인지는 장치의 벤더 ID로 확인할 수 있습니다. 패킹된 Object Identifier는 BACnet/IP 16진수 변환기의 객체 ID 탭에서 디코딩하세요.

BACnet 속성 식별자(Property_Identifier 열거형)

Property_Identifier 번호는 모든 객체 유형에서 같습니다. 속성 85는 Present_Value이며 객체가 이든 이든 같습니다.

ID속성의미

이 필터와 일치하는 속성이 없습니다.

현장에서 자주 쓰는 항목을 번호순으로 정리했습니다. 전체 열거형은 500번을 넘으며 최신 표준판마다 항목이 계속 추가됩니다. 위 번호는 포인트를 읽고, 오버라이드하고, 커미셔닝(기능 성능 검증)할 때 접하는 항목이며 85, 87, 104가 일상적으로 가장 많이 쓰이는 세 가지입니다.

BACnet 공학 단위(Units 열거형)

객체의 Units 속성(117) 값을 분야별로 묶었습니다. 전체 열거형에는 250개가 넘는 값이 있으며, 여기에는 빌딩 시스템에서 실제로 사용하는 항목을 담았습니다.
