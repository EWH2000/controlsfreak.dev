일반적인 HVAC 센서의 온도와 저항을 양방향으로 변환합니다.
일반적인 HVAC 센서—10K Type II / III, Johnson 8.7K, Schneider Type 5, 20K, 3K, Balco, Pt100, Pt1000—의 온도와 저항을 양방향으로 변환하고, 센서 종류를 모를 때는 식별 모드를 사용할 수 있습니다. 조회는 선택한 센서 종류의 온도 또는 저항을 입력받아 나머지 값과 전체 R/T 표를 제공합니다. 식별은 종류를 모르는 센서에서 측정한 (온도, 저항) 쌍을 받아 특성 곡선 적합도에 따라 모든 센서 종류의 순위를 정합니다.

# 측정 온도 측정 저항(Ω) 곡선 예측값 오차

식별 모드는 측정값을 조회 모드에서 사용하는 동일한 생성 공칭 곡선과 비교하며, 교정 데이터와 비교하는 것은 아닙니다. 센서 허용오차(일반적으로 ±0.1~±1 °C), 계측기 정확도, 자가 발열은 모두 측정값에 영향을 줍니다. 측정 지점 2개만으로는 비슷한 곡선을 구분하기 어려울 때가 많습니다. 10K Type II와 10K Type III는 모두 77 °F에서 10 kΩ을 지나며, 이 점을 벗어나야 차이가 나타납니다. 작업 조건이 허용하는 범위에서 가능한 넓은 온도 범위의 측정값을 3개 이상 사용하고, 판별이 매우 비슷한 경우에는 확정적으로 식별하지 말고 “두 종류 중 하나”로 판단하세요.

이 표에 관하여

값의 출처. 각 R/T 표는 소수의 특성 곡선 매개변수—NTC 서미스터의 β와 R25, 선형화된 10K 곡선의 병렬 분로 저항, RTD의 R0와 온도 계수—로부터 생성됩니다. Pt100과 Pt1000 표는 국제 표준인 IEC 60751 Callendar–Van Dusen 다항식을 따릅니다. 500개가 넘는 셀을 한 행씩 검토하는 대신 매개변수를 감사하여 표 전체의 신뢰성을 한번에 확인합니다.

검증에 사용한 자료(2026-05 검토). 10K Type II, 10K Type III, 10K Type 5(TAC)는 BAPI 10K-2 / 10K-3 / 10K-3(11K) 출력 표를 기준으로 하고 US Sensor “Curve G”, Sontay 호환성 차트, Vector Controls 다중 곡선 참조 자료와 교차 확인했습니다. 20K와 3K는 Vector Controls와 Sontay 자료, 1K Balco는 Schneider EcoStruxure Building Operation 저항 차트와 ACI BALCO 데이터시트, Pt100과 Pt1000은 IEC 60751:2008을 직접 기준으로 하여 Vector, Sontay, Fluke 표 생성기, pt100.de와 교차 확인했습니다. 여러 출처의 값이 일치하지 않은 경우에는 다른 기술자와 검토한 뒤 곡선을 결정했습니다.

여전히 공칭값인 항목. Johnson Controls 10K + 8.7K 분로 곡선은 공개 R/T 표가 없는 유일한 종류입니다. 정식 TE-6300 Product Bulletin URL은 문서 포털 랜딩 페이지로 리디렉션됩니다. 이 곡선은 10K Type 2 소자와 8.7 kΩ 저항을 병렬로 연결한 모델입니다. 현장의 관행적 지식으로는 확인되었지만 데이터시트로는 검증되지 않았습니다. 교정 데이터가 있는 정상 JCI 센서를 확보한 경우에는 그 데이터를 우선 참조하세요.

참조용으로 사용하고 교정에는 사용하지 마세요. 단일 β 모델은 Steinhart-Hart 곡선을 근사합니다. 분로 저항이 없는 10K 곡선에서는 적합 오차가 {{ pageMessages.unitText.nominalFitUs }}이며, 극한 조건에서는 {{ pageMessages.unitText.extremeErrorUs }}까지 커집니다. Pt100과 Pt1000은 국제 표준을 따르며 해당 표준과 정확히 일치합니다. 교정 등급의 작업에서는 실제 작업 온도에서 검증된 기준기와 센서를 직접 비교하여 측정하세요. 본 사이트나 다른 출처의 공개 표를 무조건 신뢰해서는 안 됩니다.
