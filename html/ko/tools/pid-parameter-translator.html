PID 파라미터 변환기 루프

하나의 PID 튜닝값도 이득 또는 비례대, 분당 반복 또는 적분 시간으로 표현할 수 있으며, 세 알고리즘 형식에서는 같은 세 숫자의 의미도 달라집니다.
한 컨트롤러가 표시한 방식으로 튜닝값을 입력하고 다른 컨트롤러가 요구하는 방식으로 변환하세요. 모든 값은 이 사이트의 표준 단위인 무차원 이득, 분당 반복 리셋, 분 단위 미분 시간을 사용하는 표준형(ISA)을 기준으로 변환합니다. PID 튜닝 도우미와 같은 파라미터 규칙입니다. 각 파라미터의 역할을 먼저 알아보려면 PID 기초를 읽어 보세요.

입력란에는 예제가 미리 채워져 있습니다. 확인하려는 값으로 수정하세요.

입력

0 = 적분 꺼짐

0 = 미분 꺼짐

시간 기준을 명시하세요. 같은 루프의 분당 Ki와 초당 Ki는 60배 차이가 나며 Kd는 반대 방향으로 같은 배율만큼 달라집니다. 0은 해당 동작을 끈다는 뜻입니다.

출력

입력값을 표준형(ISA)으로 해석합니다. 이득이 세 항 모두에 곱해집니다. 각 출력 그룹에는 해당 알고리즘 형식이 표시됩니다. 같은 숫자 세 개도 다른 형식의 컨트롤러에서는 다르게 동작하므로 어떤 값도 복사하기 전에 컨트롤러 문서의 형식과 일치하는지 확인하세요.

이 튜닝값에는 동등한 직렬형이 없습니다. 직렬형 컨트롤러의 상호작용에서는 항상 Td ≤ Ti/4이므로 이 숫자로 전개되는 실수 Ti′/Td′ 쌍이 존재하지 않습니다.

독립 이득을 기록할 때는 시간 기준을 항상 명시하세요. 같은 루프의 분당 Ki와 초당 Ki는 60배 차이가 나고 Kd는 반대 방향으로 같은 배율만큼 달라집니다. 플랫폼이 백분율 대신 공학 단위로 비례대를 입력한다면 PB(EU) = PB % × 스팬 ÷ 100입니다.

세 가지 형식

표준형(ISA): u = Kc · (e + (1/Ti) ∫e dt + Td · de/dt) — 하나의 이득이 세 항 모두에 곱해지므로 Kc를 다시 튜닝하면 P, I, D가 함께 스케일됩니다.

직렬형(상호작용형): u = Kc′ · (1 + 1/(Ti′·s)) · (1 + Td′·s) — 단계의 곱으로 미분 단계가 P·I 단계에 입력됩니다. 공압식 및 초기 전자식 컨트롤러의 구조이며 Ti′와 Td′가 서로 영향을 줍니다. 곱을 전개하면 숫자가 약간 다른 표준형이 되며 이 페이지가 바로 그 계산을 수행합니다.

병렬형(독립형): u = Kp·e + Ki ∫e dt + Kd · de/dt — 공통 승수가 없는 세 개의 독립 이득이므로 Kp를 바꿔도 적분 및 미분 동작은 변하지 않습니다.

실제 컨트롤러는 센서 잡음을 증폭하지 않도록 미분항에 필터를 적용해 미분 이득을 제한하기도 합니다. 이 페이지는 파라미터 변환식의 기준인 이상적인 무필터 형식을 변환합니다.

계산 예시

한 컨트롤러의 상호작용형 튜닝값이 이득 2.0, Ti 4.0 min, Td 1.0 min입니다. 표준형 컨트롤러와 독립 이득 형식에서 같은 루프에 필요한 값은 무엇일까요?

  1. 상호작용 계수: F = 1 + Td′/Ti′ = 1 + 1.0/4.0 = 1.25
  2. 이득: Kc = 2.0 × 1.25 = 2.5 → PB = 100 ÷ 2.5 = 40 %
  3. 적분: Ti = 4.0 × 1.25 = 5.0 min → 0.2 rep/min → 300 s
  4. 미분: Td = 1.0 ÷ 1.25 = 0.8 min → 48 s
  5. 독립 이득: Kp = 2.5 · Ki = 2.5 ÷ 5.0 = 0.5 min⁻¹(0.0083 s⁻¹) · Kd = 2.5 × 0.8 = 2.0 min

같은 루프인데도 형식에 따라 이득 노브에는 2.0 또는 2.5가 표시될 수 있고, 적분 노브에는 형식과 단위에 따라 4.0, 5.0, 0.2, 300 또는 0.5가 표시될 수 있습니다. 이처럼 표현이 크게 달라지기 때문에 이 변환기가 필요합니다.

변환 결과는 계산서가 아니라 현장 시험으로 검증하세요. 이 페이지의 계산은 정확하지만 컨트롤러가 실제로 어떤 알고리즘 형식을 사용하고 시간값을 분 또는 초 중 무엇으로 읽는지는 계산기가 결정할 수 없는 문서의 문제입니다. 형식이나 시간 기준을 잘못 변환하면 안정적이던 루프가 액추에이터를 마모시키거나 장비를 트립시킬 정도로 크게 할 수 있습니다. 이 도구는 변환 계산과 교차 확인을 제공하며 최종 기준은 컨트롤러 자체 문서입니다. 첫 설정값 변경 뒤 트렌드가 안정되는 것을 확인한 후 현장을 떠나세요.
