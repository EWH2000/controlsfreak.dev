BACnet/IP 16진수 변환기 BACnet

EBO와 여러 BACnet 도구가 BACnet/IP 장치에 대해 표시하는 16진수 바이트열 ↔ 점으로 구분한 10진수 IP 주소와 UDP 포트를 양방향으로 변환합니다.
16진수 → IP는 8자(IP만) 또는 12자(IP + 포트) 16진수 문자열을 디코딩합니다. IP → 16진수는 점으로 구분한 10진수 IP와 선택 입력인 포트로 문자열을 만듭니다. 기본 포트는 47808(0xBAC0)입니다. 객체 ID는 BACnet 도구에 표시되는 또 하나의 32비트 바이트열, 즉 Object_Identifier의 10비트 유형과 22비트 인스턴스를 언패킹하고 다시 하나의 값으로 패킹합니다.

BACnet/IP 주소가 16진수로 패킹되는 방식

BACnet/IP는 IPv4 주소 4바이트와 UDP 포트 2바이트, 총 6바이트로 장치를 식별하며 일부 는 이 바이트를 하나의 16진수 문자열로 그대로 표시합니다. C0A8 0164 BAC0은 포트 47808의 192.168.1.100으로 해석되며, 8자 문자열에는 주소만 들어 있습니다.

UDP 47808(0xBAC0)은 IANA에 등록된 BACnet 포트입니다. 동일한 호스트에서 논리적인 BACnet/IP 네트워크를 여러 개 운용하지 않는 한 현장에서 접할 포트는 이 하나뿐입니다. ASHRAE 135 Annex J는 추가 네트워크에 연속된 포트(47809/BAC1 이상)를 사용하는 관례를 설명하지만, 이러한 포트는 IANA에 등록되어 있지 않습니다. 현장의 실제 BACnet 설계와 대조해 확인하세요.
