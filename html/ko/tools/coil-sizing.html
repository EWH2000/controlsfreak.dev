도구 · 코일 용량 산정

코일 용량 계산기 HVAC

코일 하나의 성능을 독립적으로 계산합니다.
용량 탭에서는 입구와 출구 공기 상태를 입력해 전열·현열·잠열 용량과 비를 계산합니다. 출구 상태 탭에서는 반대로 입구 공기와 코일이 처리해야 할 부하를 입력해 출구 공기 상태를 구합니다. 습공기선도의 코일 공정과 같은 수식만 따로 제공하므로 전체 공기조화기(AHU) 공정 없이도 용량을 빠르게 확인할 수 있습니다.

입력란에는 예제가 미리 채워져 있습니다. 확인하려는 값으로 수정하세요.

입력

입구 공기

출구 공기

예제로 입력된 출구 상태(55 °F DB/ 54 °F WB)는 의도적으로 제습이 강한 거의 포화된 코일 출구 상태(약 95 % RH)라서 비가 낮게 계산됩니다. 실제 출구 공기는 보통 조금 더 건조하므로 설계 조건에 맞게 수정하세요.

가열 코일에서는 절대습도(함습비, W)가 변하지 않습니다. 출구 공기가 입구 공기의 수분량을 그대로 가지므로 출구 만 입력하면 됩니다.

계산 예

냉각 코일에 2000 CFM의 공기가 80 °F DB/67 °F WB로 들어가 55 °F DB/54 °F WB로 나옵니다.

  1. 각 공기 상태의 h와 절대습도(함습비, W) W를 ASHRAE 선도 수식으로 구합니다.
  2. 체적유량을 건공기 질량유량으로 환산합니다.
    ṁ = CFM × 60 ÷ ventering(lb 건공기/h).
  3. 전열 용량은 변화량으로 계산합니다. qtotal = ṁ × Δh. 현열은 변화량으로 계산합니다. qsens = ṁ × (0.240 + 0.444·W) × ΔDB. 잠열은 나머지인 qtotal − qsens입니다.
  4. 비 SHR = qsens ÷ qtotal는 코일 용량 중 온도를 낮추는 비율과 수분을 제거하는 비율을 보여 줍니다. SHR이 낮으면 코일이 습도가 높은 공간을 처리하고 있다는 뜻입니다.

위 공식은 엔진의 기본 IP 단위계(CFM, lb, Btu, 즉 ASHRAE IP 수식)로 작성되어 있습니다. 미터법에서는 표시 단계에서 환산하므로 보이는 입력값과 결과는 같은 IP 계산의 정확한 대응값입니다. 대기압은 해수면으로 고정됩니다. 고도를 반영하려면 습공기선도의 고도 입력을 사용하세요.

입력

입구 공기

코일 부하

대기압은 해수면으로 고정됩니다. 가열 코일의 부하는 모두 현열이며 절대습도(함습비, W)는 변하지 않습니다.

계산 예

반대로 계산합니다. 입구 공기와 코일이 처리할 부하에서 출구 공기 상태를 구합니다.

  1. 질량유량 ṁ은 용량 탭과 마찬가지로 풍량과 입구 비체적에서 구합니다.
  2. 냉각 코일에서는 부하가 하강량을 정합니다. ΔDB = −qsens ÷ (ṁ × (0.240 + 0.444·W)). 전열 부하(현열 + 잠열)는 하강량을 정합니다. Δh = −qtotal ÷ ṁ. 와 로 출구 상태점이 결정됩니다.
  3. 부하가 해당 분할에서 공기가 제거할 수 있는 수분량보다 크면 출구 상태점이 포화곡선, 즉 코일의 장치 노점온도(ADP)에 놓입니다. 상태 줄에 이를 표시합니다.
  4. 가열 코일은 순수 현열 공정입니다. 용량이 ΔDB를 정하고 절대습도(함습비, W)는 그대로이므로 출구 상태는 수분량이 같은 더 따뜻한 공기입니다.

용량 탭의 역계산입니다. 여기서 구한 출구 상태를 용량 탭에 입력하면 같은 용량이 다시 나옵니다. 용량 탭과 마찬가지로 공식은 IP 단위계 기준이며 미터법 값은 표시 단계에서 환산합니다.
