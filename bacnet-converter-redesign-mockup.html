Multiple logical BACnet/IP networks on the same host use sequential UDP ports starting at 47808. BBMDs (Broadcast Management Devices) typically share 47808 but live on different subnets — confirm against the site's actual BACnet design.

What's new in this layout — quick reference

  • Three columns side-by-side instead of a stacked single column. Input on the left, output in the middle, reference panel on the right — all visible at once, no scrolling to cross-check.
  • Property-sheet form rows (label left, value/input right, hairline divider). Replaces the current "label-above-input" pattern. This is the most "Niagara grammar" element of the redesign.
  • Reference panel alongside, not below. Sits on a slightly recessed background (--surface-3) so it reads as context rather than content. Holds a dense table that wouldn't have fit usefully on mobile anyway.
  • Tighter typography overall. Smaller font sizes for values and labels, less vertical padding inside rows, denser table. The current site reads spacious; this reads like a workstation tool.
  • Section labels in small caps. The "INPUT / OUTPUT / REFERENCE" markers are a BMS-grammar pattern (similar to property-sheet group headers) and let the columns introduce themselves without needing prose.
  • Same fonts, same colors, same accent. Visual language unchanged — only the layout and density shift. The point is to feel native to the site, not like a different site.
