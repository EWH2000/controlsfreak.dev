About

Hello — I'm a controls programmer based in the Northeast U.S. This is a side project I'm working on while exploring vibe coding. There's a genuine gap in easy reference websites for this trade, and I always find myself with a million tabs open just to write one program. This site aims to address that by being a one-stop shop for the common tools you need to get things done.

Bug reports and tool requests — contact coming soon.
